##🏎️ Vehicle Sales Performance & Market Trend Analysis

#📌 Project Overview
This project performs an end-to-end Exploratory Data Analysis (EDA) on a global vehicle sales dataset (12,000+ records). Using Python, I transformed raw sales data into actionable business insights, focusing on identifying top-performing product categories and regional market dominance.

The goal of this analysis is to help stakeholders understand sales velocity and market gaps to optimize inventory and marketing strategies.

#🛠️ Tech Stack
Language: Python

Libraries: * Pandas & NumPy: For data manipulation and cleaning.

Matplotlib & Seaborn: For statistical data visualization.

#🚀 Key Insights from Analysis
Market Dominance: Identified Classic Cars as the primary revenue driver, contributing significantly to the total sales volume.

Regional Performance: The US Market shows the highest sales density, while certain categories like Trains indicate untapped potential for growth.

Product Lifecycle: Analyzed sales trends to determine which product lines have the most consistent demand across different quarters.

#📊 Data Workflow
Data Cleaning: Handling missing values and ensuring consistent formatting across 12k+ entries.

Exploratory Analysis: Segmenting sales by product line, territory, and deal size.

Visualization: Creating distribution plots and correlation heatmaps to reveal hidden patterns in buyer behavior.

#📂 How to Use
Clone this repository.

Ensure you have pandas, matplotlib, and seaborn installed.

Run the Jupyter Notebook Vehicle_Sales_Analysis.ipynb to view the full step-by-step analysis.
